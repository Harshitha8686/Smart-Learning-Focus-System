# 🚀 Smart Learning Focus System (SLFS)

An AI-powered Smart Learning Focus System designed to improve students' productivity by tracking study sessions, monitoring focus, and blocking distracting websites during study time.

---

## 📖 Project Overview

Smart Learning Focus System (SLFS) is a Full Stack Web Application that helps students stay focused while studying. It integrates a custom Chrome/Edge Extension to automatically block distracting websites during active study sessions.

---

## ✨ Features

- 🔐 User Authentication (Login & Registration)
- 📚 Study Task Management
- ⏱️ Study Timer
- 📊 Dashboard Analytics
- 📅 Study History
- 🔥 Daily Study Streak
- 🎯 Focus Score Calculation
- 🌐 Website Blocker (Chrome & Edge Extension)
- 🚫 Automatic Blocking of Distracting Websites
- 👁️ Face Detection (AI Monitoring)
- 👀 Eye Tracking
- 📈 Subject-wise Study Analysis
- 📆 Weekly Study Trends

- Start Study Mode
- Stop Study Mode

  - YouTube
  - Facebook
  - Instagram
  - Netflix
  - Twitter (X)

## 💻 Installation

### Clone Repository

```bash
git clone https://github.com/Harshitha8686/Smart-Learning-Focus-System.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Database

Create a MySQL database:

```
slfs_db
```

Update the database credentials inside:

```
application.properties
```
